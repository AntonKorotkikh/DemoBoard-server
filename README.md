## DemoBoard-server

DemoBoard-server is the backend REST API server component of a job board MVP. This component acts as the intermediary between the SQLite database and the frontend React server ([demoboard-react](https://github.com/AntonKorotkikh/demoboard-react)).

I try to follow best practices here: concerns are separated between Controllers, Services and Repositories, each model has DTOs, a bunch of logging is implemented as well as role-based authentication and resource-based authorization.

You can find the database schema [here](docs/schema.png). ASP.NET Identity's other autogenerated tables are excluded for brevity.

The tech stack: C#, ASP.NET Core, Entity Framework, Serilog, SQLite.
